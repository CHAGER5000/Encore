          Look

          Classic is a Winamp-style player with separate windows. Modern is the simple phone layout.

          YouTube API key

          Search and playlist import use the YouTube Data API. A key is free: open the Google Cloud console, enable YouTube Data API v3, then create an API key under Credentials. The free quota covers about 100 searches a day. The key is stored only on this device.

          Import a YouTube playlist

          Paste a playlist link to copy it into your library.

          Backup

          Save your playlists to a file, or restore them on another device.

          About

          Encore plays music through YouTube's official embedded player, so videos show their normal ads and some videos can't be played outside YouTube (those are skipped). On iPhone, playback usually stops when the screen locks or you switch apps; keep Encore open on screen.
